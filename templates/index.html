About FileTrack

What is FileTrack?

FileTrack is a hardware-software integrated system created for school Guidance Offices that need a clearer way to store, locate, borrow, return, and monitor physical student records.

Designed for Guidance Office Document Management

Guidance Offices still handle important paper records such as student information sheets, counseling session forms, referral forms, good moral records, incident reports, and follow-up monitoring files. Manual storage can cause delays, misplaced files, and unclear borrowing or return history.

FileTrack solves this by combining a digital dashboard with ESP32 and RFID hardware. The website records the document, student, RFID tag, storage column, status, access logs, and hardware scan activity.

How FileTrack Works

Simple Process from Storage to Retrieval

FileTrack follows a clear process that helps users register, store, track, retrieve, and return physical documents properly.

01

Register Document

The admin enters the document ID, RFID tag, student name, student ID, document type, assigned user, and remarks.

02

Assign Location

The system assigns the record to Column 1, Column 2, or Column 3 based on the document type.

03

Track Using Hardware

The ESP32, RFID reader, LEDs, buzzer, and LCD help identify and monitor the physical document.

04

Search and Retrieve

Users can search by RFID, student name, student ID, document ID, title, or document type.

05

Record Activity

The system logs located, borrowed, returned, and hardware-scanned documents.
